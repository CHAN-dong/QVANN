# V3DB 缺项：512 GiB 条件预测（2026-10-21）

用户授权：假设512G内存机器，合理预测理论可测的V3DB缺项，超范围留空。此操作仅修改V3DB原有文字缺项，不覆盖任何已有数值实测，所有方案默认配置、索引、K、消融及其他方法曲线保持原样。

原“预算内未测”来自本机50GiB进程地址空间上限，以及200万关系元组、2^20证明域预检预算。它不等于出证已实际OOM，更不等于512GiB不可运行。

当前按512 **GiB**、单线程、相近单核性能、无换页建模，不把内存扩容当作CPU加速。33个固定query100/repeat0的实际证明形状用于标定时间、序列化、验证和RSS；结构门数沿用原审计模型，实际静态门数优先。更大证明域仍是未验证的外推。

内存判定：G留10%门数/构建填充余量后取二次幂域；该域的证明阶段RSS用大档位锚点单位行RSS的95分位系数估算，再乘1.5，另加32GiB系统和数据余量。只有该规划总量不超过512GiB才填预测。这个余量是公开工程假设，不是实测或数学内存上界，因此不能保证这些配置在任何512GiB机器必定完成。

曲线预测的实际Recall取现有20条搜索校准，不预测、插值或提高召回率。主表为数值单元格，橙色且带`*`为性能预测，`†`表示对应已有搜索校准的召回率。主表中不支持的缺项清空，批注区分内存包络不足、未达目标、实际数据集容量不足、缺索引/召回校准。

有条件可填的新增目标列：SIFT75–97%；NYTimes60–75%；GloVe45–70%；DEEP80–95%。这些只表示已有校准配置在所声明规划模型中的范围，不是算法极限。

SIFT规模表500K、1M已有BIGANN对应索引及召回校准，预测其原选定配置。5M/10M未训练/校准的规模点不在主表冒充默认召回实验；“V3DB512GiB固定预算规模”另页列出参数假设下的资源和性能，仅供参考，Recall明确未知。NYTimes和GloVe超过现有语料容量的规模格留空，原因不是RAM。

参考来源、模型系数和敏感性区间见model.json、proof-calibration-samples.json、curve-candidates.json和decisions.json。Query/Verify声明0.5–2倍、VO±15%的情景敏感性范围，不是置信区间。已有实测数据不变；不能用预测声称实测加速比。
