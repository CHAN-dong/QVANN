# Raw disclosure control and completed four-dataset quantization table

Raw retains the exact same SQ4 top-1 traversal, graph cache, node budget E and query IDs as the original four refinement schemes. It transmits all discovered vectors as float32 rather than sending SQ4 codes and selected refinements. The expansion-centric direct-content leaf commits each neighbor ID and its raw vector. A client supplied with only trusted metadata/roots reconstructs SQ4 codes from authenticated raw vectors, verifies the shared Merkle proof, replays the same SQ4 traversal and verifies exact top-k ranking among the discovered candidates. This is a raw-disclosure control, not a raw-distance graph traversal and not the HNSW-ADS baseline.

Four datasets,20 queries?3 repeats, one thread:240 fresh authenticated query runs,48 rejected tamper cases. Every trace fingerprint, ordered answer and recall matches the prior SQ4--SQ6--raw group. The other16 quantization groups are reused from their prior complete actual measurements. No estimates, performance multipliers or smoothing are applied. Raw can verify faster because it avoids the independent refinement proofs and progressive lower-bound checks; it sends larger VOs. Preserve this measured tradeoff in the paper.

The new four-dataset LaTeX is experiments/work9-quantization-20261023/quantization_four_datasets.tex. The original four-group tables and measurement files remain available. Raw rows are appended directly after those four groups in the existing work9 quantization tables, without moving or overwriting other experiments. Raw Search/VO-gen components are left blank because only whole-query timing was instrumented; requested VO and V are fully measured.
